# Desiree's MedSpa App

This is a front-end application that helps visitors of a med-spa tell staff their skin concern, and gives staff information about the condition plus FDA information about products that could potentially be used for the client. The information pulled from the FDA API (if available) includes the Brand, Purpose of the Product, and Warnings associated with the product.

## APIs Used: 
* The Clinical Tables API endpoint: 
 https://clinicaltables.nlm.nih.gov/api/conditions/v3/search
* The FDA openFDA Drug Label API: https://api.fda.gov/drug/label.json

## Documentation: 
* https://clinicaltables.nlm.nih.gov/apidoc/conditions/v3/doc.html 
* https://open.fda.gov/apis/drug/label/
* API providers: National Library of Medicine and the U.S. Food and Drug Administration. 


## Tech Stack: 

* **HTML:** Structure of the page.
* **CSS:** Layout and styling.
* **JavaScript:** Client side interactions and APIs.
